# DIKWP-SEMANTIC WORLDCORE 6.4A Delivery

This package contains a human-cognitive semantic-mathematics world-model research substrate.

## Main components

- GitHub-ready source archive
- Installable Python wheel
- Deterministic reference run
- Standalone offline dashboard
- DOCX and PDF technical report
- Reference summary, conformance and validation records
- SPDX 2.3 SBOM and SHA-256 manifest

## Quick start

```bash
python -m pip install dikwp_semantic_worldcore-2.0.0-py3-none-any.whl
semantic-worldcore demo --out outputs/reference
semantic-worldcore verify outputs/reference
semantic-worldcore conformance --out outputs/conformance.json
semantic-worldcore serve outputs/reference --port 8862
```

## Evidence boundary

This is an E2 author-side deterministic research reference in synthetic closed worlds. It does not certify phenomenal consciousness, a universal ontology, or the sufficiency of informational tuning for consciousness.
